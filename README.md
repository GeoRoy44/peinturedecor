# peinturedecor.fr

Site éditorial SEO Astro – peinture et décoration intérieure.

## Lancer

```bash
npm install
npm run dev
```

## Palette A · Chaux & Terracotta

| Rôle | Hex |
|---|---|

| Surface sable | #E8E0D3 |

| Accent terracotta | #C0603F |
| Secondaire béton | #A89F91 |

## Structure

- `src/components/HeroAnime.astro` : visuel SVG animé (Accueil + Catégories)
- `src/data/categories.ts` : catégories mères
- `src/styles/global.css` : tokens, dégradés, boutons animés, aucun CSS inline
